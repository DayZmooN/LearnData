Deep Learning

TP1 · Régression

Construire un premier réseau de neurones pour prédire une valeur continue.

Travail pratique45 minIndividuelEn groupeÀ relire
KerasrégressionMSE

Le support complet de ce cours est le notebook : Ouvrir le notebook HTML

Ce que tu vas apprendre

  • Préparer des variables numériques pour l’apprentissage.
  • Construire et entraîner un modèle de régression avec Keras.
  • Interpréter une erreur quadratique sur des données de test.

Les notions, une par une

Chaque encadré tient en trois ou quatre phrases : lis-les dans l’ordre, elles construisent l’étape suivante.

1

Prédire une quantité

En régression, la cible est numérique et continue. Le modèle produit une valeur, par exemple un prix ou une mesure.

2

Fonction de perte

La MSE calcule la moyenne des écarts entre prédictions et valeurs réelles, après élévation au carré. Une erreur importante est ainsi davantage pénalisée.

3

Échelle des variables

La standardisation met les variables sur des échelles comparables. On ajuste ses paramètres sur les données d’entraînement, puis on les réutilise.

En pratique dans ce TP

Pour prédire une consommation à partir de plusieurs mesures, la couche de sortie est généralement un neurone à activation linéaire : la prédiction n’est pas bornée entre 0 et 1.

À toi de jouer

  1. Repérer la variable cible et les variables d’entrée du jeu de données.
  2. Comparer la perte d’entraînement et la perte de validation après plusieurs époques.
  3. Expliquer dans l’unité de la cible ce que représente une erreur de prédiction.
